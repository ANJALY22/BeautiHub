# BeautiHub 💄

BeautiHub is a beauty product discovery and recommendation platform.

The goal of the project is to help users discover beauty products, understand their suitability, and receive personalized recommendations through a simple and user-friendly application.

## Project Status

🚧 Day 1 — Project Definition

The project is currently in the planning and requirements phase.

## Planned Features

- User registration and login
- User profile
- Beauty product browsing
- Product search feature
- Product filtering
- Product details
- Favorites
- Personalized recommendations
- Admin product management
